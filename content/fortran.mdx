Fortran, which was originally written in all caps as FORTRAN, is one of the oldest programming languages still known today. It was created by IBM in the 1950s, and its name comes from **FORmula TRANslation**.

Fortran was one of the first high-level programming languages designed specifically for scientific and engineering calculations. At the time, this was a huge step forward. It made it possible to express mathematical formulas, complex algorithms, and scientific computations in a way computers could actually run.

Even after many decades, Fortran is still used in some very serious fields. You can still find it in meteorology, astrophysics, chemical modeling, nuclear physics, and other areas where performance matters. Its array-oriented features, mature compilers, numerical libraries, and existing scientific codebases all matter. Performance comparisons with C++ depend on the algorithm, implementation, compiler, and hardware. For projects that run on supercomputers or require heavy numerical computation, that still matters a lot.

Fortran has also evolved over time. The first version, **Fortran I**, appeared in 1957. After that came **Fortran II**, **Fortran IV**, **Fortran 77**, **Fortran 90**, and newer versions. Each version added better syntax, new features, and more practical ways to build larger programs. **Fortran 90**, for example, added modules, array syntax, free-form source, and derived types. Structured control flow existed before that release.
